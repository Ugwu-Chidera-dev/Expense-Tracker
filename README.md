# Expense Tracker

A CLI Expense tracking program the creates an inventory with descriptions and timestamps and also logs all operations in a log book.

## Features

* Add descriptions of item with timestamps
* View all expenses in the inventory
* Search for specific expenses
* Remove items in inventory
* Filter expenses by category
* Generate summary of expenses
* Generate summary by category
* Generate monthly expenses
* Generate budget check
* Generate top spending category

## Technologies

* **Python**
* JSON file for inventory records
* Log file for logging activities
* Functions
* Loops and conditional statements
* Input validations

## How It Works

When the application starts, users are presented with a menu containing the available services:

```text
----- EXPENSE TRACKER SYSTEM -----

1. Add expense
2. View expenses
3. Search expense
4. Delete expense
5. Filter by category
6. Expense summary
7. Category summary
8. Monthly expenses
9. Budget check
10. Top spending category
11. Exit
```

The selected option determines which function from the project is executed.
